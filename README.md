# Contributions Text Displayer

A unique web tool that creates animated GitHub-style contribution grid displays with your custom text messages. Create eye-catching animated GIFs to share your messages in a creative and distinctive way!

![GIF Example](https://github.com/Jambient/Contributions-Style-Display/blob/main/images/GIFExample.gif)

## 🌟 Features

- Create animated text messages in a GitHub-style contribution grid
- Add, edit, and reorder multiple messages for sequential display
- Preview your animations with the Test feature before recording
- Record high-quality GIFs to download and share
- Simple and intuitive interface
- No installation required - works directly in your browser

## 🚀 Getting Started

### Online Version

The easiest way to use this tool is through the online version:
1. Visit [Contributions Text Displayer](https://jambient.github.io/ContributionsTextDisplayer/) in your browser
2. Start creating your messages right away!

### Local Installation

If you prefer to run it locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Jambient/ContributionsTextDisplayer.git
   ```

2. Open the `index.html` file in your web browser.

3. That's it! No build steps or additional dependencies required.

## 📝 How to Use

### Adding Messages

1. Use the text input field to add messages one at a time:
   - Type your message (up to 20 characters)
   - Click the "Add" button or press Enter
   - Messages will be automatically converted to uppercase for best display

2. Manage your messages:
   - **Edit**: Click the pencil icon to modify a message
   - **Delete**: Click the trash icon to remove a message
   - **Reorder**: Use the up/down arrows or drag and drop to change the order

### Testing Your Animation

1. Click the "Show Test" button to preview your animation.
2. The grid will display each message in sequence with a pause between them.
3. You can stop the test at any time by clicking the "Stop Test" button.
4. The status bar will show progress and current activity.

### Recording a GIF

1. Once you're satisfied with the test, click the "Start Recording" button.
2. The tool will automatically:
   - Display each message in sequence
   - Render the animation into a GIF
   - Download the completed GIF to your device

3. The progress bar will show the current recording and rendering progress.

![GIF recording explanation](https://github.com/Jambient/Contributions-Style-Display/blob/main/images/Explanation.png)

## ⚙️ Technical Details

This project uses:
- Vanilla JavaScript for the core functionality
- HTML Canvas for rendering
- GIF.js for creating the animated GIFs
- No backend or server-side processing required
